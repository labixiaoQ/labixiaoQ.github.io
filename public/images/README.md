# University emblems

These official emblems identify the universities in the education section.
Original proportions and colors are preserved. Web copies are downscaled to
240px on the longest side; CSS fits each within a 40px box.

- `nanjing-emblem.jpg`: “01校标.jpg” from the JPEG package linked by the
  [Nanjing University Office visual identity page](https://ndbgs.nju.edu.cn/zlxz/bsbz/20231012/i251602.html).
- `xidian-emblem.jpg`: “西电新标志1.jpg” from the JPG package linked by the
  [Xidian University publicity office](https://xcb.xidian.edu.cn/info/1008/1094.htm).

Retrieved 2026-11-18. The marks belong to their respective universities.
